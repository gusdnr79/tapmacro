사용자는 비개발자일 수 있다. 쉬운 말로 짧게 알린다.

1. `git status`로 저장 안 된 변경이 있는지 본다. 있으면 어떤 파일인지 쉬운 말로 알리고, 관리자에게 물어보라고 안내한 뒤 멈춘다. 절대 버리거나 덮어쓰지 않는다.
2. `git fetch --prune`
3. 현재 브랜치를 알린다 (main이면 "공식 본선", stage-N이면 "N단계 작업 중").
4. 현재 브랜치에 원격 브랜치가 있으면 `git pull --ff-only`. 실패하면 "다른 사람 작업과 겹쳤습니다. 관리자에게 연락하세요"라고 안내하고 멈춘다.
5. 결과를 3줄 이내로: 받은 변경 개수, 현재 브랜치, 다음에 할 일(`/status` 권장).
