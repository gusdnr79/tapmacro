# 단계별 범위와 수용 기준

- AC 형식: `S{단계}-{번호}`
- 검증 방법: [자동] 스크립트/테스트로 판정 · [실기기] S25 연결 필요, 자동 판정 · [사용자] 사람이 눈/손으로 확인 · [검수] 코드 리뷰로 판정
- 수치 기준 중 "측정·기록"은 합격선 없이 값을 DECISIONS.md에 남기면 PASS

## 기기 매트릭스 규칙
| 기기 | 역할 | 판정 |
|---|---|---|
| S25 (SM-S931N) | 기본 기기 | 모든 [실기기] AC 필수 |
| S24 FE (SM-S721N) | 성능 하한 | 각 단계의 [호환] AC 필수 |
| S26 울트라 (SM-S948N) | 고해상도·최신 OS | 각 단계의 [호환] AC 필수. 해상도 FHD+와 QHD+ 두 설정 모두 |

- [호환] AC: 해당 단계의 핵심 [실기기] 시나리오를 다른 기기에서 반복. 표에 기기별 결과를 따로 적는다
- 단계 완료 조건: 기본 기기 PASS + 호환 기기는 PASS 또는 BLOCKED(환경). BLOCKED(환경)인 호환 항목은 STATUS 비고에 남기고, 해당 기기 보유자가 이어받아 채운다
- 10단계 완료 전에는 세 기기의 모든 [호환] 항목이 PASS여야 한다
